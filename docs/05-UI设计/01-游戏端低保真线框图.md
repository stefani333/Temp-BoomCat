# 炸弹猫咪游戏端低保真线框图

- 版本：v1.0
- 范围：游戏网页移动端（PWA）MVP，单设备本地对局，真人 1 席 + 模拟玩家。
- 说明：本文为低保真结构稿，只描述信息层级、区域划分与交互入口，不确定视觉样式。尺寸单位为相对比例，移动端以 390×844 为基准，桌面端以 1440×900 为基准。
- 规则依据：`炸弹猫咪_规则.md` 与 `docs/03-游戏策划/01-规则拆解与MVP功能清单.md`。

## 0. 页面与流程总览

```text
首页（创建房间）
   │ 创建
   ↓
房间等待（加入/准备/指定起始玩家/开始）
   │ 房主开始
   ↓
游戏牌桌（回合、出牌、抽牌）
   ├─ 选牌面板 / 组合面板
   ├─ 效果选择浮层（目标、卡名、弃牌、放回位置）
   ├─ 休想反制浮层
   ├─ 炸弹处理浮层
   └─ 对局结束
        ↓
     结算页面（获胜者、事件日志、再来一局）
```

## 2. 房间等待与准备

```text
┌──────────────────────────────────────────┐
│ 房间号  LOCAL-0001        目标人数 4 人   │
│ 房主：我                                 │
├──────────────────────────────────────────┤
│ 座位列表                                 │
│ ┌──────────────────────────────────────┐ │
│ │ 1  我          房主   已准备           │ │
│ │ 2  模拟玩家 A  模拟   已准备           │ │
│ │ 3  模拟玩家 B  模拟   未准备  [加入]   │ │
│ │ 4  空位                       [加入]   │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ 起始玩家：[ 我            v ]            │
│ 人数：2 / 4                              │
│                                          │
│ [ 我准备 / 取消准备 ]                    │
│ [ 加入模拟玩家 ]                         │
│ [ 开始游戏 ]（人数满、全员准备、起始已选）│
│ [ 返回首页 ]                             │
└──────────────────────────────────────────┘
```

状态与禁用规则：

- 人数未达目标人数：开始游戏禁用，提示「人数不足」。
- 存在未准备玩家：开始游戏禁用，提示「有玩家未准备」。
- 未指定起始玩家：开始游戏禁用，提示「请指定起始玩家」。
- 开始后房间锁定，页面切换到游戏牌桌。

牌桌信息规则：

- 对手区只显示手牌数量、存活状态、是否当前回合，不显示手牌内容。
- 抽牌堆只显示剩余张数，不显示顺序。
- 弃牌堆顶公开，点击可查看弃牌堆列表。
- 非本人回合时，出牌与抽牌按钮禁用，等待模拟玩家行动。
- 剩余回合数大于 1 时，在回合信息区显示。

## 8. 空态与异常提示

| 场景 | 展示位置 | 文案方向 |
| --- | --- | --- |
| 人数不足 | 房间等待 | 提示还差 N 人，开始按钮禁用 |
| 未指定起始玩家 | 房间等待 | 提示请指定起始玩家 |
| 非本人回合操作 | 牌桌 | 按钮禁用，提示等待当前玩家 |
| 弃牌堆为空时尝试五张不同猫咪 | 出牌面板 | 禁用组合并提示弃牌堆为空 |
| 无拆除卡 | 炸弹处理 | 仅可确认淘汰，展示即将移出本局的提示 |
| 抽牌堆为空 | 牌桌 | 提示牌堆异常，禁止抽牌并记录问题 |
| 对局已结束 | 全局 | 拒绝改变状态的操作并返回结算页 |
