# 炸弹猫咪游戏端低保真线框图

- 版本：v2.0
- 基准：线上已部署游戏端 `https://47.243.198.214.nip.io/game/`（构建提交 `1c24cac`），线上实际页面、交互、文案与状态为唯一准绳。
- 范围：游戏网页移动端（PWA）MVP，单设备本地对局，真人 1 席 + 模拟玩家。
- 说明：本文为低保真结构稿，只描述信息层级、区域划分与交互入口，不确定视觉样式。尺寸单位为相对比例，移动端以 390×844 为基准，桌面端以 1440×900 为基准。
- 规则依据：`炸弹猫咪_规则.md` 与 `docs/03-游戏策划/01-规则拆解与MVP功能清单.md`。
- 差异处理：旧版线框中已不存在于当前实现的场景不删除，统一收进第 10 节「线框保留与差异记录」。

## 0. 页面与流程总览

```text
首页（创建房间 / 自动演示 / 查看规则）
   ├─ 创建并进入房间
   │     ↓
   │  房间等待（加入模拟玩家、我准备、开始游戏）
   │     ↓ 房主开始
   │  游戏牌桌（回合、出牌、抽牌、效果浮层、炸弹处理）
   │     ├─ 本人被淘汰 → 淘汰提示 → 继续观战
   │     ↓ 仅剩一名存活玩家
   │  结算页（获胜者、玩家结果、关键事件、完整日志）
   │     └─ 再来一局 / 返回房间 / 返回首页
   └─ 自动演示一局（全模拟玩家）
         ↓
      自动演示页（运行规则引擎整局模拟）
         └─ 返回首页
```

交互说明：

- 昵称默认「我」，最多 12 个字符；留空提交时按「我」处理。

状态与禁用规则：

- 顶部显示房间号、等待开局状态与「返回首页」按钮。

牌桌信息规则：

- 顶部显示房间号、回合数、当前玩家与「你的回合」标签；剩余回合数大于 1 时显示「剩余 N 回合」标签。
- 对手区只显示手牌数量与卡背占位、存活状态、是否当前回合（「行动中」），不显示手牌内容。
- 抽牌堆只显示剩余张数，不显示顺序。
- 弃牌堆顶公开，点击「查看弃牌堆（N）」在牌桌中区展开最近弃牌列表。
- 非本人回合或本人已淘汰时，手牌不可选择，出牌与抽牌按钮禁用，中区提示「等待 X 行动。」。
- 本人被淘汰后，顶部保留「你已被淘汰，正在观战。」，页面继续展示牌桌与日志。
- 对局日志固定内嵌在牌桌中区底部，不提供独立日志按钮或侧栏；新事件出现时自动滚动到最新一条，玩家向上滚动回看历史时不强制跳回。
- 桌面端为「牌桌中区 + 右侧手牌区」两栏；移动端为上下堆叠，手牌区在牌桌中区之后。
- 手牌区显示「我的手牌（N）」、可行动状态、卡牌、已选数量与可打出类型、行内错误提示，以及「出牌」「抽牌并结束回合」「清空选择」。
- 抽牌堆为空时抽牌按钮禁用，手牌区提示「抽牌堆为空，无法抽牌。」。

## 4. 出牌操作

单张出牌不弹确认浮层。点击「出牌」后：

- 普通行动牌（跳过、洗混等）立即打出并写入日志。
- 恩惠立即进入「选择目标玩家」浮层。
- 预见未来立即打出，随后进入「预见未来：抽牌堆顶部三张」确认浮层。
- 攻击立即打出并结束本回合，进入等待休想响应流程。
- 特殊猫咪不能单独打出，行内提示「特殊猫咪不能单独打出，请组合使用」。
- 炸弹、拆除、休想不能主动打出，行内提示「该卡牌不能主动打出」。

组合出牌：

- 两张相同猫咪：立即进入「选择目标玩家」，选择后立即打出。
- 三张相同猫咪：先进入「选择目标玩家」，选择后进入「指定卡牌名称」。
- 五张不同猫咪：弃牌堆为空时行内提示「弃牌堆为空，不能打出五张不同猫咪组合」；否则进入「从弃牌堆选择一张牌」，点击卡牌立即打出。
- 组合不合法时不弹窗，在手牌区行内提示，例如「需要相同名称的特殊猫咪」「五张组合需要名称各不相同」「无效的组合数量」。

### 4.1 等待休想响应

```text
┌──────────────────────────────────┐
│ 是否使用休想                     │
│ 模拟玩家 A 打出 攻击（高潮），    │
│ 当前反制层数 1。休想可以取消该    │
│ 效果，也可以被另一张休想反制。    │
│ （手牌无休想时）你手牌中没有休想，│
│ 只能放弃。                        │
│ [ 使用休想 ] [ 放弃 ]            │
└──────────────────────────────────┘
```

- 浮层只在本人是当前反制响应者时出现。
- 手牌中没有休想时「使用休想」禁用，并提示只能放弃。
- 牌桌中区同时显示待处理横幅：「待处理：攻击（高潮）」「等待 X 决定是否使用休想」「反制层数 1」。

## 6. 炸弹处理浮层

### 6.1 处理选择

```text
┌──────────────────────────────────┐
│ 你抽到了炸弹猫                   │
│ 使用一张拆除（消火）可避免淘汰，  │
│ 并秘密把炸弹猫放回抽牌堆。        │
│ 拆除处理不受休想影响。            │
│ 手牌中有 1 张拆除。               │
│                                  │
│ [ 使用拆除 ] [ 放弃并淘汰 ]       │
└──────────────────────────────────┘
```

放弃并淘汰需要二次确认：

```text
┌──────────────────────────────────┐
│ 你抽到了炸弹猫                   │
│ 确认放弃拆除将立即被淘汰，全部    │
│ 手牌与炸弹移出本局，操作不可撤销。│
│ [ 确认淘汰 ] [ 取消 ]            │
└──────────────────────────────────┘
```

- 手牌中没有拆除时，「使用拆除」禁用并提示「手牌中没有拆除，将被淘汰。」。
- 只有「放弃并淘汰」可用，仍需二次确认。

### 6.2 放回炸弹猫

```text
┌──────────────────────────────────┐
│ 放回炸弹猫                       │
│ 选择炸弹猫在抽牌堆中的位置，该    │
│ 位置对其他玩家保密。当前抽牌堆    │
│ 26 张。                          │
│ [ 牌堆顶部 ] [ 牌堆底部 ]         │
│ 指定位置：第 1 张为顶部，         │
│ 第 27 张为底部 [ 1 ]             │
│ [ 确认放回 ]                      │
└──────────────────────────────────┘
```

- 「牌堆顶部」「牌堆底部」点击即放回。
- 指定位置需输入 1 至当前抽牌堆张数 + 1，再点「确认放回」。

```text
│ - 模拟玩家 C 抽到炸弹猫，无拆除   │
│ - 模拟玩家 C 被淘汰               │
│ - 模拟玩家 B 成为最后存活玩家     │
├──────────────────────────────────┤
│ 完整对局日志（可滚动）            │
│ 01 房间锁定，对局开始             │
│ ...                              │
├──────────────────────────────────┤
│ [再来一局] [返回房间] [返回首页] │
└──────────────────────────────────┘
```

- 结算页不展示「对局轮次」汇总字段，回合数只在顶部标签出现。
- 「完整对局日志」只滚动，不提供「展开全部」。
- 「再来一局」按上一局胜者作为起始玩家创建新房间；「返回房间」回到等待页并保留同一目标人数。

## 9. 空态与异常提示

| 场景 | 展示位置 | 线上实际文案与处理 |
| --- | --- | --- |
| 人数不足 | 房间等待 | 元信息显示「还差 N 人」；提示「开始条件未满足：人数不足」；开始按钮禁用 |
| 有玩家未准备 | 房间等待 | 提示「开始条件未满足：有玩家未准备」；开始按钮禁用 |
| 本人已被淘汰 | 牌桌 | 弹出「你已被淘汰」浮层，关闭后顶部显示「你已被淘汰，正在观战。」；手牌与操作禁用 |
| 非本人回合操作 | 牌桌 | 手牌禁用，出牌与抽牌按钮禁用，中区提示「等待 X 行动。」 |
| 弃牌堆为空时使用五张不同猫咪 | 手牌区 | 行内提示「弃牌堆为空，不能打出五张不同猫咪组合」，不弹窗 |
| 无拆除卡 | 炸弹处理 | 仅「放弃并淘汰」可用，二次确认后淘汰 |
| 抽牌堆为空 | 手牌区 | 抽牌按钮禁用，提示「抽牌堆为空，无法抽牌。」 |
| 对局已结束 | 全局 | 拒绝改变状态的操作并返回结算页 |

## 10. 线框保留与差异记录

以下场景在旧版线框中存在，但当前线上实现已无对应入口或交互。按要求不删除内容，统一保留在本节作为差异记录；预览台中对应页面标注为「线框保留」。

| 场景 | 旧线框描述 | 当前实现 | 处理 |
| --- | --- | --- | --- |
| 首页「当前版本说明」侧栏 | 桌面端右侧版本说明面板 | 首页无侧栏，创建房间面板内直接提供规则入口与说明 | 线框保留记录 |
| 首页底部「规则摘要入口」 | 页面底部独立规则入口 | 规则入口位于创建房间面板内 | 线框保留记录 |
| 房间每座位准备按钮 | 每个模拟玩家可单独切换准备 | 模拟玩家加入即自动准备，只有本人可切换准备 | 线框保留记录 |
| 牌桌「[日志]」按钮与日志侧栏 | 顶部按钮打开日志浮层，桌面端右侧常驻日志栏 | 日志固定内嵌在牌桌中区底部，自动滚动到最新 | 线框保留记录 |
| 单张出牌确认浮层 | 「出牌 / 已选 / 效果 / 确定打出」二次确认 | 点击「出牌」后立即执行或直接进入效果浮层 | 线框保留记录 |
| 组合出牌确认浮层 | 「组合出牌 / 作为组合打出 / 重新选择」 | 无确认层，直接进入效果浮层或提交 | 线框保留记录 |
| 组合校验失败浮层 | 弹窗提示非法组合 | 改为手牌区行内提示，不弹窗 | 线框保留记录 |
| 结算页「对局轮次」字段 | 汇总区展示第 N 轮 | 回合数只作为顶部标签展示 | 线框保留记录 |
| 结算日志「展开全部」 | 日志可展开查看全部 | 日志区域仅滚动，不提供展开入口 | 线框保留记录 |
| 抽牌堆为空「记录问题」 | 提示牌堆异常并记录问题 | 提示「抽牌堆为空，无法抽牌。」，按钮禁用，不写入问题事件 | 线框保留记录 |
| 起始玩家手动指定入口 | 房间内提供指定起始玩家 | 已按产品确认移除，由系统按房主或上一局胜者确定 | 上一轮已移除，本轮确认无入口 |
