# 炸弹猫咪游戏端 MVP 验收测试报告

- 版本：v1.0
- 验收日期：2026-11-23
- 验收对象：`packages/game-core`、`apps/game-web`
- 规则依据：根目录 `炸弹猫咪_规则.md`
- 验收环境：macOS，Node.js 24.12.0，pnpm 11.27.0，系统 Chrome（headless），`http://localhost:5200/`

## 1. 验收结论

MVP 验收目标全部达成，无阻断问题。真人可在浏览器完成创建房间、加入模拟玩家、准备、指定起始玩家、开局、出牌、抽牌、处理炸弹、结算的完整流程；规则引擎在 2 至 5 人局共 20 局自动对局中均正常结束，卡牌总数保持 56 张。

未覆盖项均为本期明确的范围外能力：真实服务端、真人联机、断线重连、解散投票、PWA 安装与动画音效。

## 2. 验证方式与结果

| 验证项 | 命令或方式 | 结果 |
| --- | --- | --- |
| 规则引擎测试 | `pnpm test` | 42 项全部通过 |
| 类型检查与生产构建 | `pnpm build` | 通过，Vite 构建成功 |
| 浏览器真实对局 | `pnpm --filter @bombcat/game-web ui:smoke` | 通过，完整执行两次 3 人局并结算，页面无脚本异常 |
| 全模拟整局 | 测试内 `runFullSimulation` | 2、3、4、5 人局各 5 个种子共 20 局全部结束，均仅剩 1 名存活玩家，卡牌合计 56 张 |

浏览器冒烟共完整执行两次 3 人局（真人为起始玩家），两次均正常结算且无页面脚本异常。

第一次冒烟（真人获胜）关键记录：

```text
97  我 抽了一张牌
98  模拟玩家 C 抽到了炸弹猫
99  模拟玩家 C 没有拆除卡，被炸弹猫淘汰，全部卡牌移出本局
100 我 成为最后存活玩家，赢得对局
```

第二次冒烟（模拟玩家 B 获胜）关键记录：

```text
88  模拟玩家 B 抽了一张牌
89  我 抽到了炸弹猫
90  我 没有拆除卡，被炸弹猫淘汰，全部卡牌移出本局
91  模拟玩家 B 成为最后存活玩家，赢得对局
```

两次过程中实际触发了：真人在 UI 打出卡牌、被模拟玩家使用恩惠后选择交牌、抽到炸弹猫后使用拆除并选择放回位置、休想反制提示、模拟玩家连续行动、玩家淘汰与胜负结算。

## 4. 规则文件第 9 节验收重点映射

## 5. 异常与边界场景

| 场景 | 预期 | 结果 |
| --- | --- | --- |
| 人数不足、有人未准备、未指定起始玩家 | 拒绝开始并提示原因 | 通过 |
| 非房主开始或指定起始玩家 | 拒绝 | 通过 |
| 非当前玩家出牌或抽牌 | 拒绝 | 通过 |
| 淘汰玩家出牌 | 拒绝 | 通过 |
| 对局结束后抽牌 | 拒绝 | 通过 |
| 同一操作重复提交 | 只结算一次 | 通过 |
| 抽牌堆为空时抽牌 | 拒绝，不切换回合 | 通过 |
| 弃牌堆为空时打出五张不同猫咪 | 拒绝 | 通过 |
| 三张相同猫咪索取失败 | 三张猫咪退回手牌，不进入弃牌堆 | 通过 |
| 炸弹猫处理期间持有休想 | 不出现反制窗口 | 通过 |
| 攻击状态下再次攻击 | 转移给下一位两个回合，不叠加 | 通过 |
| 淘汰玩家手牌与炸弹 | 全部移出本局，不进入弃牌堆 | 通过 |

## 6. 问题清单

| 编号 | 问题 | 严重程度 | 当前处理 | 建议 |
| --- | --- | --- | --- | --- |
| I-01 | 单设备本地对局，规则引擎运行在浏览器内，尚无可信服务端 | 中 | 已通过独立引擎包与视图裁剪隔离，UI 不接触他人手牌 | 下一阶段将 `game-core` 迁入 Node 服务，客户端只提交操作 |
| I-02 | 真人联机、断线重连、解散投票、房主转移未实现 | 中 | 不属于本期验收范围 | 按规则 12.5 至 12.8 在联机阶段实现 |
| I-03 | 攻击状态下抽到炸弹被淘汰，剩余攻击回合如何处理，规则未明确 | 低 | 当前由下一位存活玩家从 1 个回合开始 | 提交产品确认后补规则与用例 |
| I-04 | 恩惠或两张相同猫咪的目标没有手牌时如何处理，规则未明确 | 低 | 当前判定无收益并记录公开事件，恩惠不会停留在待交付状态 | 提交产品确认 |
| I-05 | 抽牌堆意外为空时的补牌规则未定义 | 低 | 当前拒绝抽牌、保留当前回合并提示 | 按规则第 10 节第 8 项提交确认 |
| I-06 | 三张相同猫咪可指定目标不可能持有的名称（如炸弹猫） | 低 | 当前按组合失败处理 | 规则未限制名称，保持现状并在规则确认时复核 |
| I-07 | 浏览器冒烟依赖本地 Chrome 与开发服务器，未接入 CI | 低 | 已提供 `ui:smoke` 脚本与环境变量覆盖 | 后续接入 Playwright 或 CI 浏览器环境 |
| I-08 | 事件日志仅保存在内存，刷新页面后丢失 | 低 | 本期可接受 | 联机阶段由服务端持久化并支持回放 |
| I-09 | 无动画、音效与 PWA 安装清单 | 低 | 按规则「先规则正确，再视觉包装」暂缓 | 规则稳定后补充 |

## 7. 复验方式

```bash
pnpm install
pnpm test
pnpm build
pnpm dev
# 另开终端
pnpm --filter @bombcat/game-web ui:smoke
```

浏览器冒烟会实际创建 3 人房间并自动完成操作与模拟玩家推进，输出对局结果与日志尾部；退出码为 0 表示通过。
