# 游戏端线框预览台

把 `docs/05-UI设计/01-游戏端低保真线框图.md` 中的线框页还原为可运行、可点击切换的低保真页面。本工程独立于仓库主工程，自带 `package.json`、Vite 入口与启动说明，不依赖主工程路由与依赖。

线框仅表达信息层级、区域划分与交互入口，不包含后端调用与真实游戏规则实现。

## 技术栈

- React 19
- Vite 7
- TypeScript
- 原生 CSS（低保真灰阶与细边框，无 UI 组件库、无图标库）

## 目录内容

| 路径 | 说明 |
| --- | --- |

| `src/scenes/HomeScene.tsx` | 首页与创建房间 |
| `src/scenes/LobbyScene.tsx` | 房间等待与准备 |
| `src/scenes/TableScene.tsx` | 游戏牌桌、出牌、效果选择、炸弹处理与日志 |

| `src/scenes/EdgeScene.tsx` | 空态与异常提示入口 |

## 本地运行

```bash
cd docs/playground
npm install
npm run dev        # 开发预览，端口 5181
npm run build      # 类型检查并生产构建
npm run preview    # 预览构建产物，端口 5181
npm run typecheck  # 仅类型检查
```

端口固定为 5181，避开主工程的 5173、5174。

## 可点击流程

- 首页选择目标人数、起始玩家与随机种子，点击「创建并进入房间」进入房间等待。
- 房间内可加入模拟玩家、切换准备状态、指定起始玩家；条件不足时「开始游戏」禁用并显示原因。
- 满足人数已满、全员已准备、起始玩家已指定后，点击「开始游戏」进入牌桌。
- 牌桌支持选牌、单张出牌、组合识别、组合校验失败提示、目标选择、猜卡名、弃牌选择、预见未来、反制等待、炸弹拆除与放回位置、弃牌堆与日志查看。
- 牌桌状态可用外壳的「推进回合」与「重置对局」演示；非本人回合会禁用出牌与抽牌。
- 结算页提供「再来一局」「返回房间」「首页」。
- 空态与异常页的每张卡片可直接跳转到对应页面与状态。

## 说明

- 侧栏中的出牌与效果浮层页使用演示快照，便于单独评审每个浮层；页面内的实际交互仍基于当前牌桌状态。
- 设备切换用于查看同一牌桌在 390 宽竖屏与 1440 宽横屏下的两种布局。
- 本工程只修改 `docs/playground` 目录内的文件。
