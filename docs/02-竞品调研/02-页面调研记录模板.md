# Exploding Kittens 2 页面调研记录模板

使用说明：

1. 每个页面复制一份本页对应的 9 字段表格进行填写，不删除字段。
2. 每条记录先填写记录头，再填正文；无内容写「未观察到」并说明原因。
3. 只写可验证的观察与行为推断，技术架构类结论一律不写。
4. 编号与 `01-调研总览与任务清单.md` 第 4 节一致。

记录头（每份记录必填）：
